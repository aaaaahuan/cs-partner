# CS2 Grenade Partner - 自动投掷物教练

这是一款智能的 CS2 辅助工具，它通过识别小地图自动判断你的位置，并在你接近关键道具点位时，自动在屏幕上显示投掷教学。

## 核心特性

*   **完全自定义**: 内置强大的录制功能，你可以随时录制属于自己的独门点位。
*   **自动感应 (Auto-Trigger)**: 无需按键，无需菜单。当你走到点位附近时，教学界面自动弹出。
*   **双显示模式**: 支持 **F1 小窗模式** (适合熟练工) 和 **F2 幽灵模式** (全屏半透明覆盖，适合精准对齐)。
*   **雷达自适应**: 无论你使用固定雷达还是旋转雷达，智能算法都能精准识别你的位置。
*   **安全无忧 (VAC Safe)**: 基于屏幕图像识别（小地图），完全不读取内存，真正的物理外挂。
*   **云端构建**: 无需安装 Python，通过 GitHub Actions 一键生成 EXE。
*   **本地构建**: 提供了 `build.bat` 脚本，双击即可在本地生成 EXE 文件。

## 环境要求

*   Windows 10 / 11
*   **游戏设置**:
    *   显示模式: **窗口化全屏 (Fullscreen Windowed)** (必须，否则无法覆盖显示)
    *   HUD 比例: 建议默认值 (雷达未被遮挡)
    *   雷达颜色: 建议玩家箭头颜色为**白色**或亮色以确保识别准确。

## 快捷键指南

| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **F5** | **一键录制 (Record)** | 走到新点位，瞄准好，按 F5。软件会自动记录坐标并截图，立即生效！ |
| **F1** | **小窗模式 (Mini)** | 默认模式。在屏幕右上角显示瞄准截图和小字说明，不遮挡视野。 |
| **F2** | **幽灵模式 (Ghost)** | 全屏半透明覆盖模式。将参考截图铺满屏幕，让你像素级复刻瞄准点。 |

## 如何使用

### 1. 下载与运行
#### 方式一：直接下载 (推荐)
1.  访问本项目的 [GitHub Actions](https://github.com/YOUR_USERNAME/cs-partner/actions) 页面。
2.  下载最新的 **CS2Partner-Windows**。
3.  解压后双击 `CS2Partner.exe` 即可运行。

#### 方式二：本地构建 (针对开发者)
如果你熟悉 Python，也可以自己构建：
1.  安装 [Python 3.8+](https://www.python.org/downloads/) 并确保勾选 "Add Python to PATH"。
2.  下载本项目源码。
3.  双击运行根目录下的 `build.bat`。
4.  脚本会自动安装依赖并打包。
5.  完成后，你可以在 `dist/` 文件夹下找到 `CS2Partner.exe` 并运行。

**运行成功标志**:
看到屏幕顶部绿色标签 "CS2 Partner Ready" 即代表运行成功。

### 2. 录制你的第一个点位
1.  进入游戏（单机跑图或死斗均可）。
2.  找到一个你想要记录的投掷点（比如 Mirage A点跳台烟）。
3.  站定位置，将准星对准参考物（比如木板上的钉子）。
4.  按下 **F5**。
5.  屏幕提示 "Recorded: Custom Nade..."。
6.  搞定！下次你再走到这里，屏幕右上角就会自动弹出你刚才的截图。

### 3. 数据管理
所有录制的数据都保存在软件同目录下的 `cs_partner_data` 文件夹中：
*   `grenades.json`: 存储所有点位的坐标和描述。你可以用记事本打开它，修改点位名称（例如把 "Custom Nade 123" 改为 "Mirage Jungle Smoke"）。
*   `images/`: 存放瞄准截图。
*   `minimaps/`: 存放雷达指纹（用于智能识别）。
