# CS2 Grenade Partner - 自动投掷物教练

这是一款智能的 CS2 辅助工具，它通过识别小地图自动判断你的位置，并在你接近关键道具点位时，自动在屏幕上显示投掷教学。

## CS2 投掷物实操知识

### 投掷物种类

| 道具                       | 名称                   | 核心用途              |
| :----------------------- | :------------------- | :---------------- |
| 烟雾弹 (Smoke)              | Smoke Grenade        | 遮断视线、阻挡狙击、掩护推进或撤退 |
| 闪光弹 (Flash)              | Flashbang            | 致盲敌人、配合队友强攻点位     |
| 高爆弹 (HE)                 | HE Grenade           | 伤害敌人、清除盾牌手、骚扰守点   |
| 燃烧瓶 (Molotov/Incendiary) | Molotov / Incendiary | 封锁通道、逼敌人移动、阻断回撤路线 |
| 诱饵弹 (Decoy)              | Decoy Grenade        | 声东击西、模拟枪声迷惑敌人     |

### 三种投掷方式

| 操作            | 投掷类型    | 适用场景     |
| :------------ | :------ | :------- |
| **左键单击**      | 正手投（最远） | 远距离烟雾/闪光 |
| **右键单击**      | 抛投（最近）  | 近距离封路燃烧  |
| **左键 + 右键同时** | 中距离投掷   | 中程高爆/闪光  |

### 点位 (Lineup) 的核心要素

一个完整的投掷点位由 **三要素** 构成，缺一不可：

1. **站位 (Position)**: 玩家脚下的精确位置，通常需要贴墙、卡角，甚至"像素走位"到特定坐标。
2. **瞄准点 (Crosshair Placement)**: 将准星对准屏幕上某个参考物（建筑边角、纹理细节、天空中某个点）。这是决定落点的关键。
3. **投掷方式**: 使用上述三种投法中的哪一种。

### 小地图（雷达）说明

小地图位于屏幕**左上角**，是识别玩家位置的核心依据。

- **玩家箭头**: 三角形图标，指向玩家的朝向。
- **固定雷达 vs 旋转雷达**: 固定雷达始终以地图北方为上；旋转雷达以玩家视角为上，需要算法补偿旋转角度。
- **雷达缩放**: 游戏内可调，影响识别精度，建议保持默认缩放比例。

## 核心功能描述

### 产品定位

CS2 Partner 是一款运行在游戏窗口之上的**实时道具教练**。它持续"盯着"你的屏幕，当它判断出你正站在某个经典投掷点位附近时，主动将这个点位的瞄准参考图叠加显示在你的屏幕上——就像一个老手坐在你旁边，在恰当的时机提示你"这里有个烟，这样瞄"。

你不需要暂停游戏去查攻略，不需要打开浏览器搜视频，也不需要死记硬背数十个点位。**你只需要打游戏，它来提醒你。**

### 核心体验流程

```
玩家移动 → 软件实时识别小地图位置 → 匹配附近点位 → 自动弹出瞄准参考 → 玩家对齐准星 → 投出完美道具
```

整个过程对玩家完全透明，没有打断，没有额外操作。

### 两种展示模式

软件提供两种显示形态，适应不同学习阶段：

**小窗模式（日常使用）**

参考图以小窗口形式出现在屏幕一角，占用视野极小。适合已经对某个点位有一定印象、只需要"校准"一下准星位置的玩家。在不影响正常游戏操作的情况下，随时可以瞥一眼参考。

!\[Inferno 点位示例1]\(../assets/inferno/1.png 小窗模式示意 - 参考图出现在屏幕角落，绿色十字线指示精确瞄准点)

> **① 左上角红框区域**：软件持续监测的小地图区域，用于实时判断玩家当前位置。
> **② 屏幕中央绿色十字线**：叠加在参考截图上的瞄准辅助线，玩家将游戏准星与之对齐即可完成精确投掷。

**幽灵模式（精准练习）**

参考图以半透明蒙层的方式铺满整个游戏画面，游戏内容与参考图同时可见。玩家可以像拓印一样，将自己的准星与蒙层上的瞄准线完美重叠，适合初次学习某个点位时使用。

!\[Inferno 点位示例2]\(../assets/inferno/2.png 幽灵模式示意 - 参考截图半透明覆盖全屏，可像素级对齐瞄准点)

> **① 左上角红框区域**：同上，小地图识别区域。
> **② 全屏绿色十字线**：在幽灵模式下，辅助线横贯全屏，配合半透明参考图，像素级对齐不再困难。
> **③ 左侧文字提示**：软件叠加的补充说明，包括站位提示、投掷按键提示（左键/右键/双键）等关键信息。

## 核心功能设计

### 1. 实时位置感知

软件在后台持续截取屏幕左上角的小地图区域，通过图像识别技术判断玩家在地图中的当前坐标。这一过程对玩家完全无感——软件不介入游戏进程，只是"看着"屏幕上的公开画面信息。

- **识别频率**：保持实时响应，玩家走动时位置判断持续更新。
- **兼容雷达设置**：无论玩家使用固定雷达（地图永远朝北）还是旋转雷达（随视角转动），软件均能正确换算坐标，无需玩家改动游戏设置。
- **触发范围**：每个点位有一定的"感应半径"，玩家进入该范围即触发，不需要站在像素级精确位置才能激活。

### 2. 点位自动触发与展示

当软件判断玩家进入某个点位的感应范围时，自动弹出对应的瞄准参考界面。玩家离开该区域后，界面自动收起。整个过程不需要任何按键操作。

**展示内容**：

- 该点位的瞄准参考截图（完整的游戏视角画面）
- 叠加在截图上的十字瞄准辅助线，标明精确的准星落点
- 简短的文字说明：点位名称、道具类型、投掷方式（左键/右键/双键）

**交互细节**：

- 参考界面弹出时带有轻微淡入动效，不突兀。
- 玩家可随时按 `ESC` 或指定快捷键手动关闭当前提示，关闭后在同一区域内不再重复弹出（直到下次进入）。
- 当同一位置存在多个可用点位时（例如同一站位可以扔 A 点烟也可以扔 B 点烟），界面以卡片列表形式展示，玩家可左右切换浏览。

### 3. 双模式切换

两种展示模式可在游戏中实时切换，满足不同场景需求：

| <br />   | 小窗模式 (F1)      | 幽灵模式 (F2)      |
| :------- | :------------- | :------------- |
| **界面形态** | 屏幕角落小窗，不遮挡主视野  | 半透明蒙层铺满全屏      |
| **适合场景** | 正式对局中快速参考      | 练习服/死斗中精细学习    |
| **操作影响** | 几乎无影响，可正常游戏    | 全屏覆盖，建议停下来对齐   |
| **切换方式** | 按 F1 / F2 即时生效 | 按 F1 / F2 即时生效 |

### 4. 一键录制新点位

软件内置录制功能，允许玩家将自己独创或从攻略视频学来的点位直接录进本地库，立即生效。

**录制流程**：

1. 在游戏中走到目标投掷站位，站稳。
2. 将准星对准参考物（如建筑边角、纹理细节）。
3. 按下 `F5`，软件自动完成以下所有操作：
   - 截取当前画面作为瞄准参考图
   - 记录当前小地图坐标作为触发位置
   - 生成一个默认名称的点位条目
4. 屏幕顶部短暂显示"录制成功"提示，即刻生效。

**录制后管理**：

- 录制完成的点位可通过配套的本地数据文件（纯文本）修改名称和描述，例如将自动命名的"Custom Nade 001"改为"Inferno B 香蕉烟"。
- 支持删除、导出、分享给队友使用（导入对方的点位包）。

### 5. 安全性设计

软件采用**纯屏幕画面读取**方式工作，不与游戏进程交互，不读取游戏内存，不修改任何游戏文件。其工作原理等同于玩家自己看着屏幕做判断，因此对反作弊系统（VAC）完全透明，不存在封号风险。

这一设计决策也决定了产品的一个核心约束：**需要窗口化全屏模式**运行游戏，以便软件能够在游戏画面之上绘制覆盖层。

## 环境要求

- Windows 10 / 11
- **游戏设置**:
  - 显示模式: **窗口化全屏 (Fullscreen Windowed)** (必须，否则无法覆盖显示)
  - HUD 比例: 建议默认值 (雷达未被遮挡)
  - 雷达颜色: 建议玩家箭头颜色为**白色**或亮色以确保识别准确。

## 快捷键指南

| 按键     | 功能                | 说明                                |
| :----- | :---------------- | :-------------------------------- |
| **F5** | **一键录制 (Record)** | 走到新点位，瞄准好，按 F5。软件会自动记录坐标并截图，立即生效！ |
| **F1** | **小窗模式 (Mini)**   | 默认模式。在屏幕右上角显示瞄准截图和小字说明，不遮挡视野。     |
| **F2** | **幽灵模式 (Ghost)**  | 全屏半透明覆盖模式。将参考截图铺满屏幕，让你像素级复刻瞄准点。   |

## 如何使用

### 1. 下载与运行

1. 访问本项目的 [GitHub Actions](https://github.com/YOUR_USERNAME/cs-partner/actions) 页面。
2. 下载最新的 **CS2Partner-Windows**。
3. 解压后双击 `CS2Partner.exe` 即可运行。
4. 看到屏幕顶部绿色标签 "CS2 Partner Ready" 即代表运行成功。

### 2. 录制你的第一个点位

1. 进入游戏（单机跑图或死斗均可）。
2. 找到一个你想要记录的投掷点（比如 Mirage A点跳台烟）。
3. 站定位置，将准星对准参考物（比如木板上的钉子）。
4. 按下 **F5**。
5. 屏幕提示 "Recorded: Custom Nade..."。
6. 搞定！下次你再走到这里，屏幕右上角就会自动弹出你刚才的截图。

### 3. 数据管理

所有录制的数据都保存在软件同目录下的 `cs_partner_data` 文件夹中：

- `grenades.json`: 存储所有点位的坐标和描述。你可以用记事本打开它，修改点位名称（例如把 "Custom Nade 123" 改为 "Mirage Jungle Smoke"）。
- `images/`: 存放瞄准截图。
- `minimaps/`: 存放雷达指纹（用于智能识别）。
